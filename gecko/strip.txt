# Firefox's own UI, deleted from the source tree before the build (gecko/build.ts).
# One path per line, relative to the tree; globs allowed; '#' starts a comment.
# What stays is the engine and the behaviour Toji relies on: gBrowser's tab model
# (tabbrowser), session restore, prompts and permission requests, the page
# context menu, the menubar, downloads' backend and Save dialog, printing, the
# WebExtension APIs uBlock Origin needs, Picture-in-Picture, the profile
# migrators (not their wizard), the search service, the shell service, devtools,
# about:addons, PDF.js and the diagnostic pages. docs/gecko.md, "Firefox
# contributes nothing", explains each group.
